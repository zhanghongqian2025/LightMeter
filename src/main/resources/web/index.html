处理范围以可解析文本为主，不等于「整份文档所有内容都已脱敏」。 图片文字被提取出来或 PDF 存在 OCR 文本层，不等于图片像素已被涂黑。 扫描后请阅读该格式的具体限制说明。

一次可以写多个，用逗号或换行分开。补的词会出现在上面的清单里， 你仍然可以勾掉它。只对这一份文件有效。

填了口令，下载的映射文件会被加密（文件里没有原文），还原时要用同一个口令； 留空则不加密，映射文件里会有原文。

完成

映射文件是还原的唯一凭据：脱敏件里只有令牌，没有原值。请把映射文件与脱敏件一起保存。

映射文件已用口令加密（文件里没有原文）。 重启程序后，在「还原已保存的脱敏文件」中选择这份脱敏文件、加密映射文件， 并输入同一个口令即可还原。

还原的是文本内容：文档属性清空、签章移除、数值单元格转文本这些动作不可逆， 还原件与原件在文本上一致，但不是同一个文件。

还原已保存的脱敏文件

程序重启后也能使用。请选择同一次脱敏生成的脱敏文件和加密映射文件； 服务会核对文件长度与 SHA-256，不匹配时不会还原。 这里只支持新版、带脱敏成品校验信息的加密映射文件； 旧版未绑定映射无法在重启后安全确认配对，会被拒绝。

独立还原上限：映射文件 16 MiB、10,000 条映射、单条原值 1,048,576 个字符， 累计文本增长 67,108,864 个字符。超限时不会生成还原文件； 大型映射请先在原任务完成页保存还原件，再退出程序。

选择两个文件并输入口令后才会开始。

退出本机服务

退出前请先确认脱敏文件和映射文件都已保存。 退出会停止本机服务并清理本次会话的临时文件； 正在处理的文档会被请求取消，某些格式可能要到下一个安全检查点才停下。

关闭浏览器页面不会自动退出服务。

访问控制姿态

外部网页可以对本机发请求，但读不到响应（同源策略），也构造不出带令牌的写请求 （自定义头会触发预检，本服务不答预检）。这两条是本服务对外部网页的全部防护面。
