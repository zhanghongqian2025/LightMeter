# 字节级闸门的豁免清单（tools/check-sources.sh 读它）
#
# 【什么时候需要登记】
#   只有当某个位置**故意**用到 U+FFFD 这个字符本身（不是「某个字被写坏了」）
#   才登记。判断标准很简单：
#     · 这个字符在代码里有**语义**（它就是那个要表达的东西）→ 登记；
#     · 这个字符是**某个字被替换掉了的残骸** → 不要登记，那是损坏，要还原。
#   闸门会拦下所有没登记的替换符。登记错了 = 把损坏放过去，
#   所以每条都**必须写清理由**，写不出理由的多半是损坏，不是故意用法。
#
# 【格式】
#   <文件路径> | <命中行里必须出现的片段> | <为什么允许>
#   - 路径相对仓库根
#   - 片段用**字面**匹配（不是正则），且必须与替换符**出现在同一行**
#   - 一行一条；# 开头是注释
#
# 【豁免不会一直有效】
#   片段一旦在源码里不存在了，闸门会报「豁免失效」并要求删掉这一条 ——
#   免得清单里躺着早就没用的例外，逐渐变成「什么都放行」的后门。
#
src/main/java/com/litemask/pdf/ShowTextOp.java | static final String UNDECODABLE = | 这个常量**故意**就是 U+FFFD：PDF 里的字符解不出来时用它表示（见该常量的注释）。不是损坏。
