# LightMeter 安装与使用说明

面向**不需要懂技术的普通用户**。全程只需要**双击**和**点击**，
不需要打开命令行、终端、PowerShell，也不需要装 Java 或配置环境变量。

---

## 一、安装（Windows）

1. 拿到 `LightMeter-1.1.4.msi`（或 `LightMeter-1.1.4.exe`）。
2. **双击它**，跟着提示点「下一步」直到装完。
   - 不需要管理员权限，不需要关闭杀毒软件，不需要改任何系统设置。
   - 装到 `%LOCALAPPDATA%\LightMeter\`，只影响你自己这台机器上的你这个账户。
3. 桌面上会出现 **LightMeter**（也可以从「开始菜单 → LightMeter」打开）。

## 二、安装（macOS）

1. 拿到 `LightMeter-1.1.4.dmg` 或 `LightMeter-1.1.4.pkg`。
2. `.dmg`：双击打开，把 `LightMeter.app` 拖进「应用程序」文件夹。
3. `.pkg`：双击，跟着提示装完。
4. 首次打开若系统提示「无法验证开发者」，这是因为**没有购买 Apple 的代码签名证书**。
   在「系统设置 → 隐私与安全性」里点「仍要打开」即可。
   **不需要**去关闭 Gatekeeper 或任何系统安全功能。

---

## 三、第一次打开

双击 LightMeter，浏览器会自动打开一个本地页面。

页面最上面是「**识别模型**」一栏。首次启动时程序会**自己**把识别模型准备好：

- 会出现「正在校验」「正在安装」——这是**真实进度**，不是假装的。
- 几秒后变成「**人名与机构名识别已就绪**」。

**这一步不需要你做任何事**，也不要去找什么「模型路径」。

> 如果这一栏显示的是「未安装」或「损坏」，往下看 §六「装不上怎么办」。

---

## 四、处理文档

1. 点「选择一个文件」，选你的文档（支持 docx / xlsx / pptx / pdf / ofd / txt）。
2. 点「开始扫描」。
3. 屏幕上会出现一张**命中清单**——里面是被识别出来的敏感信息。
   - **默认全部脱敏**。
   - 勾选某一行 = 保留那个值（不脱敏）。
   - 同一个值出现多次时，每处前面还有一个小勾选框，勾上它 = **只保留那一处**。
4. 想补规则认不出来的名字（比如某个当事人、某个内部代号），
   在清单下面的「**补充敏感词**」里填上，点「加入并重扫」。
   补的词会出现在清单里，你可以再勾掉它。
   > 一次至少填 2 个字：一个字会命中全文每一个字。
5. 点「生成脱敏文件」，然后「下载脱敏文件」。

### 一定要保存映射文件

脱敏文件里**只有令牌，没有原文**。**映射文件是还原的唯一凭据**——
丢了就再也还原不回来。请把映射文件和脱敏文件**放在同一个地方保存**。

---

## 五、还原

在「完成」那一栏点「**还原并下载**」，就能拿回内容一致的还原件。

> 还原的是**文本内容**，不是文件字节：文档属性被清空、签章被移除、
> 数值单元格转成了文本——这些动作不可逆。

如果你在生成脱敏文件时填了**映射文件口令**，还原时需要同一个口令。

---

## 六、装不上模型怎么办

「识别模型」那一栏会直接告诉你**卡在哪一步**，以及**下一步该做什么**。

| 你看到的 | 意思 | 你该做什么 |
|---|---|---|
| 正在安装 / 正在校验 | 正在准备，等一下 | 不用管 |
| 人名与机构名识别已就绪 | 好了 | 不用管 |
| 尚未安装 | 没找到可用的模型 | 点「**安装识别模型**」 |
| 损坏 | 装了一半或文件坏了 | 点「**重试**」 |
| 更新失败 | 新版本没装上 | 点「**重试**」或「**恢复上一版本**」——**原来那一版仍然能用** |
| 签名验证没通过 | 这个模型包不是本产品发布方签发的 | 别装它；用「**选择离线模型包**」换一份 |

### 选择离线模型包

如果你的机器装不上、或者拿不到随安装包分发的那份模型：

1. 拿到一个**离线模型包文件**（一个 `.zip`，里面已经带着模型和它的验证材料）。
2. 点「**选择离线模型包**」→ 选中那个文件 → 等它显示「已就绪」。

**你只需要选这一个文件**，不需要自己去找 `.sha256`、`.sig` 或公钥。

### 没模型也能用，但结果要人工核对

模型不可用时，身份证号、手机号、银行卡这类**有固定格式**的信息照样会脱敏，
但**人名与机构名不会被脱**。这时页面会一直挂着一句提示：

> 当前未启用人名与机构名识别，结果需要人工处理。

并且要你**勾选确认**才能开始扫描。**请务必人工核对**——这是这份工具最需要你留意的地方。

---

## 七、升级

直接双击新版安装包即可。

- **不用先退出正在运行的 LightMeter**：程序自己会看见「安装器来了」，
  把资源交还之后自己退出，安装接着完成。
- **你的模型、设置与用户数据都会保留**（它们在 `%LOCALAPPDATA%\.litemask\`，
  和程序目录分开，升级不会动它们）。

> 极老的一个例外：从 **1.0.0** 升级时，如果 1.0.0 当时**正在运行**，
> Windows 不允许覆盖正在使用的文件，需要先把它关掉再装。
> 从 **1.1.2** 起就没有这个限制了（程序会自己看见安装器、自己让位）。

---

## 八、卸载

控制面板「已安装的应用」里卸 `LightMeter`（macOS：把 `LightMeter.app` 拖进废纸篓）。

**卸载不会删**你保存的原件、脱敏件与映射件——那些是你的文件。

---

## 九、你的数据在哪里

| 东西 | 位置 | 说明 |
|---|---|---|
| 程序 | `%LOCALAPPDATA%\LightMeter\` | 升级/卸载会动它 |
| 识别模型 | `%LOCALAPPDATA%\.litemask\models\ner\` | **升级不会动它** |
| 识别模型的历史版本 | `%LOCALAPPDATA%\.litemask\models\ner.versions\` | 可以在界面上「恢复上一版本」 |
| 日志 | `%LOCALAPPDATA%\.litemask\logs\litemask.log` | 出问题时给技术支持看 |
| 你的文档 | 你自己选的地方 | 程序**不**保存你的原件 |

**文档内容不出本机。** 程序只在 `127.0.0.1` 上提供服务，同网段的其它机器连不上，
每次启动生成一次性会话令牌。下载识别模型时也**不会**夹带你的文档、OCR 文本或身份映射。

---

## 十、遇到问题

1. 先看「识别模型」那一栏的状态——它会直接说明原因和下一步。
2. 再看日志：`%LOCALAPPDATA%\.litemask\logs\litemask.log`。
3. 把这两样一起给技术支持，比截图有用得多。
